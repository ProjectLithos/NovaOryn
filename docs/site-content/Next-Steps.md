# SDK Next Steps

## 0.0.43 — Public API completion

Audit intended end-user assemblies, make accidental implementation details internal, document every supported public item, add examples and enable strict documentation validation.

## 0.0.44 — SDK reference packaging

Package reference assemblies, architecture assets, templates and offline documentation behind one controlled SDK reference model.

Complete the architecture-neutral contracts and isolate x64-specific implementations before beginning the ARM64 QEMU virt target.

Add boot memory-map contracts, physical-page allocators, early allocation and replaceable heap designs.

Build interrupt/event foundations, Get/Set/Event system calls, scheduling, processes, executable services, drivers and filesystems as user-selectable SDK facilities.
